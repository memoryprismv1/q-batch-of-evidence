# Examples

Examples should be based on real runs and retain enough context to interpret the evidence. Do not invent example results and present them as observations.

A useful example should include:

1. The question being tested and the expectations written before execution.
2. A completed batch record for each run.
3. The preserved response, log, and result artefacts, with sensitive information removed.
4. An offline comparison record.
5. A short account of what the evidence supports, what remains uncertain, and any contamination or environment-reset limitations.

## First intended example

The method arose when a run intended to test **Blind** followed a run of **Prism** in the same ChatGPT account/context. Prior exposure meant the later run could not be treated as independent.

A future case study can document independent Prism and Blind batches, their separate resource-loading conditions, their evidence sets, and a comparison performed after both sets exist. Until those runs and artefacts are collected, this is the motivating scenario—not a completed validation result.
